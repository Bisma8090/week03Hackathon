# Tea E-Commerce Platform

A full-stack, production-level Tea E-Commerce Platform built using the MERN stack. This project follows real-world backend architecture where all core business logic is handled on the server side, and the frontend focuses only on rendering UI and making API calls.

---

## Features

- User Registration & Login with JWT authentication
- Role-based access control (Superadmin, Admin, User)
- Product & Variant Management
- Backend-based Pagination, Filtering & Sorting
- Cart Management (Add, Update, Remove items)
- Order Placement & Tracking
- Stock validation & automatic stock updates
- Admin & Superadmin dashboards
- Secure APIs with middleware protection

---

## Technologies Used

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (jsonwebtoken)
- bcryptjs
- React.js (Frontend)
- Tailwind CSS + MUI
- express-validator
- dotenv
- Postman

## Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Bisma8090/week03Hackathon.git
   ```

2. Navigate to the project directory:

   ```bash
   cd week03Hackathon
   ```

3. Install the required dependencies:

   ```bash
   npm install
   ```

5. Start the application:

   ```bash
   npm start 
   ```
   or
    ```bash
   npm run dev 
   ```
